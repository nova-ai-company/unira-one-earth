## How to use this archive
1. Read `01_PROJECT_MASTER_SPECIFICATION.md` for the actual agreed vision and non-negotiable rules.
2. Read `02_RESEARCH_HISTORY_AND_FINDINGS.md` for version-by-version findings and methodological caveats.
3. Read `03_EVIDENCE_REGISTER_AND_CAVEATS.md` before treating any statistic as verified.
4. Read `04_MODEL_ARCHITECTURE_AND_GAPS.md` and inspect `source_tree/` and `historical_packages/` for code and original notes.
5. Follow `05_ROADMAP_AND_PARALLEL_WORKSTREAMS.md` and `06_CLAUDE_AGENT_BRIEF.md` to continue.
6. `07_OPEN_DECISIONS_AND_RISKS.md` lists unresolved choices and scientific risks.
7. `08_ARCHIVE_MANIFEST.csv` inventories the actual bundled source files with SHA-256 hashes.

**Critical:** The version numbers record incremental prototypes, NOT independent scientific validation. Synthetic tests establish software behavior under assumptions, not real-world outcomes. Source claims may require rechecking, especially geography, years and denominators. Prior assistant claims about completed models are not proof: read the implementation and rerun tests.

**Archive layout:** `handover/` curated documents; `source_tree/` available extracted source code/data/notes; `historical_packages/` all locally available historical ZIPs; `historical_documents/` prior working papers and drafts. Some earlier conversations mentioned files that are not present; do not assume all versions have complete source.
