# UNIRA V5.7 research package

- `model.py`: executable synthetic monetary and physical stocks model
- `test_model.py`: 13 automated tests
- `results.json`: five scenario outputs, including event logs and sector balance sheets
- `RESEARCH_NOTE.md`: findings, methodology, limitations and next steps

Execute `python model.py && python -m unittest -v` in this folder.

**No empirical validation is claimed.**
