# UNIRA V5.9 package

- `model.py`: runnable 20-year six-sector physical model.
- `test_model.py`: 10 unit tests.
- `annual_results.csv`: all scenario-year diagnostics.
- `results.json`: full machine-readable scenario results.
- `RESEARCH_NOTE.md`: method, assumptions, results, limitations and next steps.

**All numerical parameters are synthetic.** The currency U in investment fields is not calibrated to real purchasing power.
